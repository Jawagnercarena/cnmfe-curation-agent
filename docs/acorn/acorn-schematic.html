The payoff

Why it beats running CNMF‑E by hand

Vanilla CNMF‑E extracts candidates — everything else is manual, every session, forever. ACORN automates the front‑end, pre‑filters the junk, and gets better the more you use it.

CNMF‑E by hand

Every session, from scratch.

  • Eyeball 5 parameters per session by staring at the correlation and PNR images.
  • Inspect and delete every candidate by hand — often several hundred per session.
  • Nothing carries forward — the next session starts from zero. The work never gets easier.
  • One operator at a time; consistency drifts between people and days.
Human touchpoints every step, every session

With ACORN

Drop the file, review the shortlist.

  • Parameters set automatically from the animal profile and the image statistics.
  • Confident junk is removed before you look; motion and split‑cell pairs are flagged for you.
  • Every review retrains the model — so there's less to review the next time.
  • Reviewing distributes across a team against one canonical model per brain area.
Human touchpoints one review — shrinking each cycle

Where the model's judgment comes from

Trained on real, human-curated neurons

The classifier only ever learns from decisions a person actually made — and it didn't start from zero. It inherited years of the lab's manual curation.

Direct review

Curated inside ACORN

Every session you review turns your keep / delete / merge calls into labeled examples — about 8,400 cells reviewed directly so far, and growing with every session. This is the online‑retraining loop from the pipeline above.

Bootstrap

Inherited from prior hand-curation

The lab had already hand‑curated ~7,700 neurons from older recordings with manual CNMF‑E. ACORN re‑extracts those recordings and spatially matches each new candidate to that trusted set — a match is a real neuron, everything else a reject — seeding the model with tens of thousands of labeled cells before its first ACORN review.

Under the hood: ACORN wraps CNMF‑E (Zhou et al., 2018). The curator is an XGBoost classifier over standardized 13‑feature vectors, with one canonical model per brain area (BLA, vCA1), retrained automatically whenever a new set of human labels lands. Work is staged out to reviewers and pulled back through a shared exchange so the labeling network scales past a single machine. Like the acorn: a small model goes in, a sharper one comes out — every cycle.
